👤 로그인 전

⚠️ 현재 실행 환경에서 브라우저 저장이 제한되어 있어요. 학습은 가능하지만 창을 닫으면 기록이 사라질 수 있습니다. Chrome/Edge에서 다운로드한 HTML 파일을 직접 열어 주세요.

이 Chapter에 나만의 단어를 추가할 수 있어요. 학습 기록과 추가 단어는 로그인한 계정의 Firebase에 저장됩니다.

원서에 등장하는 중요 어휘와 관련 확장 어휘를 구분했습니다. 예문은 학습용으로 새로 작성했습니다. 한글 발음은 근사치이며, 특히 새로 추가한 단어의 한글 표기는 자동 생성되어 실제 발음과 다를 수 있습니다.

☁️ 학습 진도는 Firebase에 자동 저장됩니다. 동일한 Google 계정으로 로그인하면 다른 기기에서도 이어서 학습할 수 있어요. JSON 백업도 권장해요. 발음 듣기는 브라우저의 영어 음성 기능을 사용합니다.

🍀 나만의 영어 단어장

구글 계정으로 로그인하면 Chrome, Edge, 휴대폰에서도 학습 기록을 이어서 볼 수 있어요.

Firebase 설정을 확인하는 중이에요.

학습 기록은 로그인한 계정의 전용 공간에 저장됩니다. 이름만 입력해서 다른 사람의 기록을 열 수 없어요.
